## 6. Before you publish – checklist

- Make the GitHub repo **private**; deliver code per buyer after payment.
- Put up a live demo instance (a cheap VPS) with `php artisan app:demo` data and a read-only demo login.
- Decide and write your **licence terms** (what a buyer may/may not do).
- Don't claim things not in the product (e.g. GST filing, e-invoicing, WhatsApp integration) – buyers will test.
- Keep the page honest about support period and what is customisation vs. included.
